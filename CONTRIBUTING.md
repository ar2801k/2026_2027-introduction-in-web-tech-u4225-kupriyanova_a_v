# CONTRIBUTING

## Порядок работы

1. Основная ветка проекта — `main`.
2. Разработка выполняется в ветке `develop`.
3. Изменения добавляются через отдельные коммиты.
4. После завершения работы изменения из `develop` объединяются с `main` через Pull Request.
